# Global Skills

全局 skill 负责多项目协作、全栈任务编排和文档组织。

## 列表

- `mom-agent-workflow/`: MOM 角色化 Agent 调度与交付质量协作 skill
- `mom-code-quality-compliance/`: 后端/Web 代码规范执行、自检和复核证据 skill
- `mom-context-budgeting/`: 主对话上下文预算、worker 派发阈值、长日志摘要和证据落盘 skill
- `mom-database-investigation/`: 真实库只读调查、生产库边界、大表查询、字段口径和 SQL 证据落盘 skill
- `mom-delivery-branch-hygiene/`: defaultBranch/upstreamBranch、feature 基线、cherry-pick、test commit 隔离和 cleanup 分支卫生 skill
- `mom-doc-organization/`: 根目录文档整理与命名 skill
- `mom-frontend-pattern-search/`: Web/低代码/报表页面开发前同域样例、API、VxeGrid、导出、权限、国际化和 MagicAPI 模式搜索 skill
- `mom-lightweight-etl-report/`: MOM 轻量 ETL 报表架构、口径治理与落地执行 skill
- `mom-praxis-command-contract/`: Taskfile、.praxis/commands.toml、.praxis/manifest.toml、task.py 和规则文档命令契约一致性 skill
