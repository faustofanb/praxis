# MOM Rules

本目录统一沉淀 IFC MOM 工作区的开发规范和交付规则。

## 目录说明

- `global/`: 跨项目通用规则
- `projects/`: 按子项目拆分的专属规则

## 导航

- `global/README.md`
- `projects/README.md`

## 设计说明

### 全局 Rule

- `01-开发总则.md`: 业务贴合现状、优先复用、最小正确改动
- `02-代码质量与注释规范.md`: 注释不可缺失、代码质量和日志异常要求
- `03-性能与稳定性规范.md`: 后端、Web、PDA、大屏的性能与稳定性底线
- `04-本地开发与交付工作流.md`: `develop`、`local`、`feature/*` 的职责边界
- `05-需求文档组织规范.md`: `docs/` 需求目录命名、多轮文档组织与根目录约束
- `06-Praxis任务执行规范.md`: Praxis 任务分发、worktree、验证等级和脚本入口

### 项目 Rule

- backend: 架构、继承、命名、事务、Flyway、功能设计
- web: 前端总规范、API、表单、权限国际化、公共包导入
- pda: 项目结构、API、路由、样式、移动端性能、工作流
- big-screen: 开发、构建与部署

## 维护原则

- 项目专属约束不默认上升为全局规则
- 至少两个项目共享的约束，才评估提升为全局规则
- 修改规则后同步更新对应 README 导航
