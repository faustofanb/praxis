# 轻量 ETL 产出物与验收

## 定位

本文件约束报表/ETL 需求的产出物清单、正式迁移前中间产物、验收证据和交付说明。它不替代 `06-交付收口.md`，而是补充报表链路特有的交付证据。

## 必要产出物

完整报表需求至少沉淀：

- 需求拆解和数据调查记录。
- 菜单模块归属说明，包含系统、菜单编码、菜单名称、路径或无法确认原因。
- 指标口径卡。
- PostgreSQL 函数/视图 SQL 与 COMMENT 注释脚本。
- `rpt_debug_*` 对账视图或函数。
- `rpt_doc_*` 口径说明入口，或等价口径说明文档。
- MagicAPI 脚本和接口说明。
- 积木报表数据集、参数、展示和导出说明。
- 验收 SQL、对账样例、风险与待确认项。

## 中间产物与正式迁移

- 迁移脚本、DDL、菜单授权、低代码模型/应用设计和 MagicAPI 迁移 SQL 先写需求目录 `04-产出物/`。
- 新需求 SQL 中间产物优先使用 `04-产出物/SQL/`，历史需求已有中间文档时才沿用旧目录。
- 正式 Flyway 迁移目录只能在收尾确认后写入，并且必须能追溯到中间产物和差异复核记录。
- 报表需求的 ETL SQL 内容默认按可直接复制到正式目录的正式版表述编写；是否已落库由路径、收尾确认和交付说明区分，不靠正文写“草案”降级。

## 验收清单

- 参数边界：空参数、单值、多值、日期边界、跨月/跨班次。
- 数据对账：总数、金额/数量、明细抽样、异常状态和空数据。
- 权限与租户：组织、菜单、角色、数据权限和租户过滤字段。
- 分页排序：分页总数、排序白名单、导出与页面一致性。
- 性能风险：大表过滤条件、索引利用、刷新/补算策略和超时风险。
- 口径版本：版本号、适用范围、下游影响和回滚方案。

## 交付说明

交付说明必须列出：

- 中心 ETL 资产路径和需求目录反链。
- dbx 查询环境、关键 SQL/对象和样例证据路径。
- 正式迁移路径或尚未进入正式迁移的原因。
- MagicAPI/积木报表/大屏影响范围。
- 已执行验证命令、对账结论、未验证项和人工复核路径。
