# Codex Workflow Rules

本目录承载 Praxis 工作流细则，替代原来单个超长的 `../06-Praxis任务执行规范.md`。

## 文件职责

- `01-入口与自动化.md`：入口、项目短名、脚本和自动化边界。
- `02-主对话与Subagent.md`：主对话、subagent、上下文预算和通信协议。
- `03-调查门禁.md`：数据库调查、数据口径、迁移中间产物。
- `04-需求文档与Worktree.md`：需求文档、README、worktree 和分支。
- `05-大任务拆分与验证.md`：拆分原则、验证等级和验证命令。
- `06-交付收口.md`：feature 交付、提交筛选、迁移收尾和清理。
- `07-过程改进与维护.md`：`todo.md` 和规则维护。
- `08-轻量ETL报表工作流.md`：PostgreSQL 函数/视图、MagicAPI、积木报表和报表口径治理。
- `09-Praxis重型化路线.md`：方法论转译、工程控制层、命令收口和受控演化路线。

## 使用方式

先从 `../00-工作流精简索引.md` 判断当前任务需要哪一类规则，再只读取对应文件。
