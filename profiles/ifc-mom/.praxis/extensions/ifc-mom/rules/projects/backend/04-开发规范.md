# 开发规范

## 代码风格

- 使用统一格式化配置
- 遵循阿里巴巴 Java 开发手册
- 使用 4 个空格缩进
- 单行长度不超过 120 字符

## 注释规范

- 类和方法必须有完整 JavaDoc
- 字段必须有中文注释
- 复杂业务逻辑必须有行内注释
- 注释不写无意义编号

## 导入规范

- 按 Java 核心类、第三方库、项目内部类分组导入
- 删除未使用导入

## 日志规范

- 使用 SLF4J
- 使用占位符格式输出日志
- 包含必要业务标识，不暴露敏感信息

## 安全要求

- 所有外部输入都必须校验
- 禁止拼接原始 SQL
- 注意租户隔离、数据权限和状态合法性
