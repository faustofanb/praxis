# 命名与建模规范

## 命名规范

- Entity：`{Module}{Business}{Entity}`
- Service：`{Module}{Business}{Entity}Service`
- ServiceImpl：`{Module}{Business}{Entity}ServiceImpl`
- Manager：`{Module}{Business}{Entity}Manager`
- Mapper：`{Module}{Business}{Entity}Mapper`
- Controller：`{Module}{Business}{Entity}Controller`
- SaveVO：`{Module}{Business}{Entity}SaveVO`
- UpdateVO：`{Module}{Business}{Entity}UpdateVO`
- ResultVO：`{Module}{Business}{Entity}ResultVO`
- PageQuery：`{Module}{Business}{Entity}PageQuery`
- 面向 QMS_PAD 的 BFF Controller 方法名必须带清晰业务语义，因为方法名会参与生成前端 API key；避免直接使用 `page`、`submit`、`getDetail` 等泛化命名生成 `qms.page`、`qms.submit` 一类歧义 key。

## 建模要求

- 表名采用下划线格式
- 包路径遵循现有 lamp 模块路径
- 字段优先使用制造业标准术语
- 查询参数超过 3 个时优先封装为 Query
- 不直接把 Entity 暴露给前端
