# 父类继承与特性接口规范

## 常规继承

- Controller 继承 `SuperController`
- Service 接口继承 `SuperService`
- Service 实现类继承 `SuperServiceImpl`
- Manager 继承项目既有 Manager 基类或 MyBatis-Plus 服务基类
- Entity 一般继承 `BaseExtEntity<Long>`

## 特性接口

根据业务特征实现对应接口：

- 编码：`CodeFeature`
- 状态：`StateFeature`
- 树形：`TreeFeature`
- 租户：`TenantFeature`

## 约束

- 启用特性接口时，要同步补齐对应字段和能力
- 例如编码唯一性校验、状态批量更新、树查询和节点移动
