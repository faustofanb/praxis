# 注解与事务规范

## 常用注解

- `@RestController`
- `@Tag`
- `@Operation`
- `@ApiResponse`
- `@Validated`
- `@Valid`
- `@RequestBody`
- `@Schema`
- `@TableName`
- `@TableField`

## 事务规范

- 读操作使用 `@Transactional(readOnly = true)`
- 写操作使用 `@Transactional(rollbackFor = Exception.class)`
- 事务粒度适中，避免长事务
- 避免在事务中调用高风险外部服务

## Controller 约束

- 标准 CRUD 优先复用 `SuperController`
- 如需覆写标准路径，必须直接覆写同名方法，避免 Spring MVC 映射冲突
