# 功能设计规范

## 设计原则

- 业务驱动，紧贴制造业实际场景
- 高内聚低耦合
- 可扩展
- 标准化

## 功能结构

- 严格遵循 Controller -> Service -> Manager -> Mapper 分层
- 对外接口要有清晰输入输出说明
- 异常处理、日志记录和接口语义保持标准化

## 建模与命名

- 字段、表、接口、类命名参考制造业标准术语
- 接口命名遵循 RESTful 风格

## 其他要求

- 涉及界面、报表、打印时考虑国际化
- 高频操作、批量处理和大数据量查询要做性能评估
