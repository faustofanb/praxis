# 项目概览与技术栈

## 项目概述

IFC MOM PDA 仓库族是基于 uni-app + Vue 3 + TypeScript 的跨平台 PDA 项目，目前包括 `ifc-mes-pad`、`ifc-mes-pda`、`ifc-tpm-pda`、`ifc-qms-pad`、`ifc-wms-pda`。

## 核心技术栈

- 框架：uni-app
- 语言：Vue 3 + TypeScript
- UI 组件库：wot-design-uni
- 请求库：Alova
- 路由：uni-mini-router + 文件路由
- 状态管理：Pinia
- 样式：UnoCSS
- 构建工具：Vite

## 开发原则

- 类型安全
- 组件化
- 响应式
- 规范化
- 性能优先
- 移动端优化优先
