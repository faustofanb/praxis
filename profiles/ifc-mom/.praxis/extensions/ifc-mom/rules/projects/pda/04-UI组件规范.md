# UI 组件规范

## 组件选择优先级

1. 优先复用项目已有组件
2. 其次使用 `wot-design-uni`
3. 最后使用原生 `uni-app` 组件

## 组件目录

- 通用组件：`src/components/`
- 业务组件：`src/business/`

## 组件要求

- 支持主题切换和多端适配
- 复杂逻辑不要堆在页面组件中
- 全局交互优先复用统一组件
