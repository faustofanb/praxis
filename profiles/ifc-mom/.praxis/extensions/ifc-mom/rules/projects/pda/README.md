# PDA Rules

适用于 `ifc-mes-pad`、`ifc-mes-pda`、`ifc-tpm-pda`、`ifc-qms-pad`、`ifc-wms-pda` 的移动端 PDA 规范。

## 执行入口

PDA 需求不能只读本 README。Execution/Quality Agent 必须按改动类型展开读取下列细则，并在回报中列出已检查的规则文件。

## 规则清单

- `01-项目概览与技术栈.md`：仓库族、技术栈、平台差异和基础约束。
- `02-项目结构规范.md`：页面、组件、业务组件、composable、store、API 目录边界。
- `03-路由规范.md`：uni-app 页面路由、tabBar、跳转和参数传递。
- `04-UI组件规范.md`：wot-design-uni、uni 原生组件和业务组件复用顺序。
- `05-API开发规范.md`：Alova、生成 API、QMS_PAD/MES_PDA 特殊接口约束。
- `06-状态管理规范.md`：Pinia store、页面态和跨页共享态边界。
- `07-样式规范.md`：UnoCSS、主题、深色模式和移动端样式底线。
- `08-移动端性能规范.md`：弱网、扫码、长列表、动画、图片和渲染性能。
- `09-开发工作流规范.md`：调试、生成、验证和交付检查。

## 必读组合

- 新增或修改页面：`01`、`02`、`03`、`04`、`07`、`08`、`09`。
- 接口或 DTO 调整：`01`、`05`、`09`；涉及后端契约时同步读后端接口/命名规则。
- Store 或跨页流程：`02`、`03`、`06`、`08`。
- 扫码、待处理、离线/弱网流程：`03`、`05`、`06`、`08`、`09`。
