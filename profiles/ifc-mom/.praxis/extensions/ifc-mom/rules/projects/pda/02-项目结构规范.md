# 项目结构规范

## 目录结构

- `src/api/`: API 管理
- `src/components/`: 全局组件
- `src/business/`: 业务组件
- `src/composables/`: 组合式函数
- `src/layouts/`: 布局模板
- `src/pages/`: 页面目录
- `src/store/`: Pinia store
- `src/utils/`: 工具函数

## 约束

- 页面文件必须放在 `src/pages/`
- 通用组件与业务组件分开存放
- API 统一通过 Alova 管理
- 样式优先使用 UnoCSS
- TypeScript 提供完整类型定义

## 来源

- 原 PDA uni-app 仓库 `.cursor/rules/project-structure.mdc`
