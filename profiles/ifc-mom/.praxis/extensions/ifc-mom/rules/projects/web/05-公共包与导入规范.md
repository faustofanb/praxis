# 公共包与导入规范

## 导入规范

- 公共枚举优先从 `@ifc/enums-common` 导入
- 公共工具优先从 `@ifc/utils` 导入
- 公共 API 优先从 `#/api/common-api` 或对应聚合入口导入
- 不再使用旧路径导入已迁移的公共模块

## 新增公共模块规范

新增前先评估：

1. 是否被多个项目使用
2. 是否与具体业务无关
3. 是否稳定且不常变动

根据能力类型选择：

- 枚举：`@ifc/enums-common`
- 工具函数：`@ifc/utils`
- API：`@ifc/api-common`

## 包维护规范

- 所有 `@ifc` 包使用 `unbuild`
- 禁止使用 `stub` 模式
- 保持 `package.json` 的 `exports`、`types`、`main` 与现有包一致
