# 表单开发规范

## 核心约束

- 使用 `useVbenForm` 管理表单
- schema、视图、API 分层明确
- 新增、编辑、查看态切换显式处理
- 默认值、回填、校验、提交形成闭环

## 校验规则

- 简单校验直接写 schema
- 复杂条件校验使用 `zod`
- 后端已有字段校验时优先合并，不手工重复复制

## 动态表单与弹窗表单

- 表单组件对外暴露明确契约
- 不把外层开关逻辑写进表单内部
