# 权限、国际化与消息规范

## 权限

- 路由访问层由路由守卫与后端菜单资源控制
- 页面按钮使用显式权限控制
- 无权限时提供降级展示
- 工具栏和批量操作要有权限与状态约束

## 国际化

- 文本优先复用现有 locale key
- 避免页面中硬编码业务文案

## 消息提示

- 统一使用现有消息或通知封装
- 提交成功、失败和常见异常路径都要有反馈
