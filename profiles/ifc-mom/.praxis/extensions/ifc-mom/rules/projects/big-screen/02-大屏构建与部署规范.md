# 大屏构建与部署规范

## 构建方式

### 全量构建

```bash
npm run build
```

### 单独构建指定看板

```bash
npm run build:dashboard -- <看板名称>
```

## 构建输出

- `dist/<dashboard>/`
- `dist/vendors/`
- `dist/echarts/`
- `dist/fonts/`

## 部署要求

- 全量部署时上传整个 `dist/` 内容
- 单独部署时同步上传对应看板目录和共享资源
- Nginx 需正确配置看板路由、静态资源缓存、字体 CORS 和 API 代理

## 性能建议

- 静态资源启用长期缓存
- HTML 不缓存或短期缓存
- 启用 Gzip 压缩
- 必要时将 vendors、echarts 放到 CDN
- 单独构建时避免不必要地清理整个 `dist/`

## API 代理

- 通过 Nginx 或开发代理统一转发 `/magic/api`
- 配置合理的连接、发送和读取超时

## 验证建议

- 部署前验证对应看板路由可访问
- 检查 API 是否正常代理
- 检查静态资源与字体是否可加载
- 检查看板缩放适配是否正常
