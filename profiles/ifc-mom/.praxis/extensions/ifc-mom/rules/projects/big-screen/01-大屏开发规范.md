# 大屏开发规范

## 项目概述

`LargeVisualizationScreen` 是面向制造业车间实时生产管控的大屏项目，基于 Vue 2.7 + Webpack 5 构建，支持多看板架构。

## 技术栈

- Vue 2.7
- Element UI 2.15
- ECharts 5.4
- Webpack 5 + Babel 7

## 项目结构

```text
config/
src/
├── dashboards/
├── shared/
public/
webpack.config.js
babel.config.js
package.json
```

## 新建看板规范

1. 在 `src/dashboards/` 下创建新看板目录。
2. 至少包含：
   - `index.html`
   - `index.js`
   - `style.css`（可选）
   - `assets/`（可选）
3. 在 `config/dashboards.config.js` 注册看板。

## 页面与样式约束

- 设计稿尺寸默认 1920x1080
- 通过 `transform` 做屏幕缩放适配
- 资源路径使用绝对路径：
  - 图片：`/看板名称/assets/图片名.png`
  - 字体：`/fonts/字体名.ttf`

## 开发约束

- 优先复用 `src/shared/` 下的配置、样式和工具函数
- API 调用优先复用共享请求工具
- 大屏展示避免默认一次性加载超大历史数据
- 图表和页面初始化逻辑保持简洁，避免无必要重复监听和重复渲染

## 常用命令

```bash
npm install
npm run dev
npm run build
npm run build:dashboard -- <看板名称>
npm run build:report
```
