## Failure Acceptance

- [x] crash after side effect before result event -> indeterminate -> reconcile
  - 命令：`bunx vitest run tests/integration/agent-loop-recovery.integration.test.ts tests/recovery.test.ts tests/fault/`
  - 证据：可落定（write_file 落盘后崩溃）→ 入口 reconcile → ToolReconciled 定论、turn 以定论事实收口；不可落定 → TurnCompleted + SessionPaused + exit-paused，模型不被咨询，绝不盲重试。reconcile 的诚实边界（策略拒绝 → indeterminate 而非 failed，failed 是唯一解锁重执行的结论）由 `tests/security/bypass-composition.security.test.ts` 钉死。
- [x] path/capability bypass attempts rejected
  - 命令：`bunx vitest run tests/security/`
  - 证据：组合层——授权齐全 + 逃逸路径 → 可证 ToolFailed 且 root 外零效果；崩溃后 symlink 改指无法把 reconcile 变成重执行解锁；伪造 INDETERMINATE 流不落定论；symlink 别名 root 不满足词法 scope；bash 无 shell.exec 在 ToolStarted 前拒绝。分层矩阵见 `capability-policy.security.test.ts`（重提案 N 次理由逐字相同、execute 计数 0、argumentsJson 无法影响授权）与 `tools-local-write.security.test.ts`（traversal/绝对/symlink 逃逸全拒）。

## Design–Implementation Consistency (docs/07 §6)

- 新增 package？无。M3 全部在既有 contracts/core/tools-local 内完成。
- 新增 Core dependency？无新包依赖；core 新增内部模块（capability/、agent-loop/recovery.ts、append-event.ts 提取）。
