## Failure Acceptance

- [x] malformed model output — 三层证据：
  1. CLI 边界：畸形脚本文件 fail loud，真二进制演示 `JSON Parse error: Expected '}'`（exit 1）；脚本耗尽 fail loud（`tests/cli`）
  2. Provider 边界：非 JSON data line、wire schema 不符、缺 finish_reason、无 id/name 的工具调用片段 → `providerError {kind:"unknown", retryable:false}`，绝不硬转（`tests/provider-openai/chat-provider.test.ts` malformed 用例）；越界 finish_reason（content_filter）同样如实上报
  3. 契约边界：词汇外事件类型/非法迁移一律拒绝（M1 reducer/contracts 套件沿用有效）
- [x] provider cancellation/timeout — 三层证据：
  1. Port 律：abort 信号下空流、不抛错、无终态事件（`tests/testkit-scripted-model.test.ts` waitForAbort 三用例）
  2. Loop 律：静默结束的流被记为 `ModelRequestFailed`，turn 保持可恢复并返回 cancelled（`tests/agent-loop.test.ts`）；CLI SIGINT→AbortController 协作取消，exit 2 + resume 提示
  3. Adapter 律：预取消/中流取消均静默结束且不重试；读超时（非调用方取消）→ `providerError {kind:"timeout", retryable:true}`（`tests/provider-openai` cancellation 两用例 + timeout 用例）
