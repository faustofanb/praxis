# 实施计划

## 一、总体目标

验证安装态、工作空间集成和版本 CLI，并留下可重复核验的产出物与审计记录。

## 二、范围说明

执行 `uv run praxis --root . version --json`，保存输出，注册测试报告，完成需求状态流转。

## 三、不在本次范围内的内容

不修改业务代码，不连接外部数据库，不启动交互式 Agent。

## 四、阶段划分

1. 将需求推进到 ready/in-progress。
2. 执行版本命令并保存测试报告。
3. 注册产出物，填写验收结论并完成需求。

## 五、阶段依赖

依赖本地 uv 环境与已安装的 `praxis-next@personal` 插件。

## 六、风险与回退方案

若命令失败，保留错误输出并停止完成状态；本次新增配置均可由 Git 精确查看和回退。
