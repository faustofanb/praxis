# 实施计划

## 一、总体目标

新增风险驱动 `fast_fix`：单文件微小变更可用一个 `praxis fix record` 幂等完成约束、验证省略、证据、产出物和 implementation 登记，同时将禁止机械命令与假测试规则写入 Agent managed guidance。

## 二、范围说明

- 新增 `fix.record` CLI / application operation。
- 新增 `FastFixService` 与工作树 + HEAD + 文件指纹证据。
- 支持 `declined` 与 `direct` 两种验证结论；命令本身不执行验证。
- 增加微小/小型命令预算及超预算新风险说明。
- 更新 AGENTS/CLAUDE managed block 与 README。
- 添加面向可观察行为的聚焦测试。

## 三、不在本次范围内的内容

- 不删除或改变 `fix start|finish`。
- 不新增 MCP 工具、依赖、数据库表或后台进程。
- 不自动拦截 shell 命令；通过 agent 指引约束前置价值判断。
- 不运行完整测试、全量类型检查、全量构建或 reviewer。

## 四、阶段划分

1. 创建隔离工作树并取得 CodeGraph 或明确不可用证据。
2. RED：CLI 映射、单文件登记、验证省略、预算与幂等证据测试。
3. GREEN：实现服务、分派、指引与文档。
4. 聚焦测试、最小 Python 编译和 `git diff --check`。
5. 提交、集成开发分支并重新安装。

聚焦行为测试命令：

```bash

  -m pytest -q tests/test_fast_fix.py tests/test_agent_guidance.py \
  tests/test_interfaces.py tests/test_application_dispatch.py --no-cov
```

```bash
  -m py_compile src/praxis/fastlane/fast_fix.py src/praxis/application.py \
  src/praxis/cli/__init__.py src/praxis/agents/guidance.py
```

## 五、阶段依赖

实现基于本地开发分支 HEAD `17fb33b`，因为其中包含尚未推送的 v2 快速通道。公共 CLI 编辑前必须完成 CodeGraph 新鲜度检查。

## 六、风险与回退方案

所有改动位于独立分支；可通过移除 `fix record` 分派、服务与 guidance 段回退，不影响既有 `fix start|finish`。聚焦验证失败时不登记实施完成。
