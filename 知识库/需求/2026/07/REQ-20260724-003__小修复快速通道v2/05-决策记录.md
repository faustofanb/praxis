# 决策记录

## ADR-1：新 fix 薄层，不改 fast v1

保留 `praxis fast ...` 与标准 profile 的缓存键和行为；`small-fix-v2` 使用独立状态 scope/profile。

## ADR-2：固定 SHA 跳过模板工作区同步

`resolve_template_revision()` 只 fetch 并解析远端模板 commit；传入 `base_revision` 时
`create_for_requirement()` 跳过 `_sync_default_branch()`，其余生命周期复用。

## ADR-3：范围优先、基线回退

仅独立 `{files}` token 启用变更文件类型检查，避免 shell 插值。未配置 token 时复用 fast v1
基线指纹和诊断比较；基线不可用只允许结论为 inconclusive。

## ADR-4：一个产出物覆盖完整变更

small-fix 将真实 Git 状态中的未跟踪测试/封装路径显式传给 ArtifactService；标准产出物行为不变，
避免把无关未跟踪治理文件纳入归档。
