# 变更记录

## 2026-07-21

- 采用需求 ID 在前的聚合工作空间命名，并把仓库关联为子目录。
- 同一需求的各开发阶段复用一个 `praxis/<需求ID>` 分支。
- 状态绑定从分支键解耦，生命周期、Agent 和 MCP 同时支持新旧绑定。
- 修复 Skill 完成状态和门禁兼容性缺陷。
- 将 `grilling@1.1.0` 加入调查阶段必需 Skill。
- 工作树创建和重复创建均以 CodeGraph 就绪作为 active 前置条件。
- CodeGraph 查询增加 binding/worktree 作用域，修正根仓库状态混用。
- 增加 Skill gate 审计、可选 stage、业务 Skill 项目过滤和投影内容保护。
- Praxis 绑定状态覆盖 Worktrunk 的误报 mismatch，同时保留原始诊断字段。
- 工作树支持显式离线依赖准备命令，并将成功准备纳入 CodeGraph 前置条件。
- Fork 可见的工作树末级目录和开发分支同时包含需求 ID 与固定简称，并提供正式名称迁移命令。
