# 实施计划

## 一、总体目标

修复 REQ-20260817-004 暴露的 5 个工作流摩擦点，并让已安装 matt 技能进入自动路由。全部为校验/输出层增强，不改变 fail-closed 语义（只新增两个显式放行口：`--reset`、`--from implemented`）。

## 二、范围说明

1. **record-implementation fail-closed**：service 层对空列表项目检查既有 implementation 条目，已有非空 artifact_ids 时返回新错误 `REQUIREMENT_IMPLEMENTATION_RESET_REQUIRED`（data 列出已有 ids 与提示），仅显式 `--reset` 允许清空；CLI 加 `--reset`；未提及项目字段保持原值（测试固化）。错误码目录补条目。
2. **implemented 单步回退**：`requirement reopen --id <id> --from implemented --reason <原因>` 单步回 in_progress；domain `reopen` 支持 implemented→in_progress（显式来源）；非允许来源仍拒绝，但 `REQUIREMENT_REOPEN_STATUS_INVALID` 的 data 附 hint（implemented 时提示 `--from implemented`，通用提示 fast 通道），错误码目录补条目；审计事件带 from_status。
3. **Maven skip 检测**：新增前端命令 `praxis test-hint --path <仓库路径> [--module <模块>] [--mvn <mvn>]`：扫描 pom.xml 属性（`*surefire.skipTests`/`*surefire.skip`/`maven.test.skip` 且值为 true）与 surefire 插件配置，命中时输出含 `-D<属性>=false` 覆盖的完整 `mvn test` 命令（含 `-pl <module>` 当提供）；未命中输出基础命令。SKILL.md TDD 段补一行指引。
4. **提交钩子登记**：`worktree ensure` 每仓库 item 增加 `commit_hooks` 字段：检测 `.husky/pre-commit`、`.pre-commit-config.yaml`、`.git/hooks/pre-commit`（非 sample）、package.json 含 husky/lint-staged；附说明「钩子触发的校验属于提交流程的一部分，不视为未授权运行」。bundled SKILL.md 第 4 节补该声明。
5. **advance 产出物提示**：advance 成功迁入 implemented 后，枚举需求 active binding 的 git 改动文件（tracked diff + untracked exclude-standard），减去已登记 artifact 的 source 文件集，非空时 data 输出 `artifact_hint`（完整 `praxis artifact add --requirement <id> --type code-change --source <路径> --stage implemented --binding <binding_id>` 命令）与未登记文件列表；fail-open 不阻塞。
6. **matt 技能自动路由**：node-routing.toml 为已安装 matt 技能补 conditional 条目：`code-review`（verifying，评审触发）、`implement`（in_progress，实施触发）、`diagnosing-bugs`（investigating/in_progress/verifying，缺陷触发，补位未安装的 systematic-debugging）、`resolving-merge-conflicts`（in_progress，冲突触发）、`ask-matt`（captured/investigating，技能选择触发）。全部 conditional 模式，不新增硬门禁。
