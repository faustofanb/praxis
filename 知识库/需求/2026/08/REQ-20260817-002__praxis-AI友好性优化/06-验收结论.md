# 验收结论

## 1、验收范围

praxis 对 AI（Codex/Claude Code 等编码代理）的友好性优化，本次落地高优先级方案 A（`praxis guide` 任务导向引导）+ 方案 B（错误码自助查询与输出 hint）。目标：AI 第一次接触 praxis 就能按任务拿到下一步命令序列，遇错时错误输出直接给出中文含义与可复制恢复动作，降低学习成本与无效往返。

## 2、功能验收

- **方案 A：`praxis guide` 任务导向引导**
  - 新增 `praxis guide`（无参）按当前工作区状态输出「我现在该做什么」：未登记需求时提示先走 `new-requirement` 场景；已登记需求时提示查看需求状态并路由节点门禁。
  - 新增 `praxis guide --scenario <new-requirement|create-worktree|tdd|verify|fast-fix>`，输出对应场景的分步命令序列（登记需求→路由调查、预览/创建绑定工作树、TDD RED→GREEN→最小编译→登记实施、验证矩阵执行→decline 登记→节点门禁→推进、fast_fix 触发条件与收尾 `fix record`）。
  - 受管块（AGENTS.md/CLAUDE.md）补一行指针：不确定下一步时运行 `praxis guide` 获取当前状态对应的命令序列，错误码含义用 `praxis errors <CODE>` 查询。
- **方案 B：错误码自助**
  - 新增 `src/praxis/guides/errors.py` 错误码目录（约 40 个高频码：REQUIREMENT_*/WORKTREE_*/SKILL_*/APPROVAL_*/ARTIFACT_*/RTK_*/CODEGRAPH_*/DBX_*/OPERATION_NOT_FOUND 等），每码含中文 `hint` + `next_step`（可复制恢复命令）。
  - 错误输出（非 `--json` 机器消费场景）默认追加「提示：… / 下一步：…」两行；`ok/code/data` 机器包络契约不变。
  - 新增 `praxis errors [code]`：无参列出目录全部条目与计数，带 code 查询单条含义与恢复动作；未知码返回标准 `ERROR_NOT_FOUND` 默认提示。

## 3、异常场景验收

- `praxis guide --scenario <非法值>`：argparse 校验拒绝（exit code 2），不进入应用层，测试覆盖。
- `praxis errors <未登记码>`：返回 `ERROR_NOT_FOUND` 默认提示而非崩溃，测试覆盖。
- 非工作空间目录运行 `praxis guide`：返回 `WORKSPACE_NOT_FOUND`，提示先 `praxis init`。
- 错误码集合本身未增删改（只新增 hint/next_step 渲染与查询入口），既有依赖错误码文本的测试全过。

## 4、数据校验

错误码目录以数据文件登记；`errors` 无参输出返回条数（`count`），与目录实际条目一致。
