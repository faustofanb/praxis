# 插件开发治理


## 领域目标

- 以可审计、低上下文成本的方式治理 AI 工程交付

## 职责边界

- 维护需求生命周期、门禁、上下文、产出物与插件发布

## 核心实体

- 需求
- 工作树绑定
- Skill 路由
- 产出物
- 系统画像

## 关键流程

- 需求登记 → 调查规划 → 隔离实施 → 验证交付 → 发布安装

- 状态与审计以 Praxis 存储为准

- Codex 插件
